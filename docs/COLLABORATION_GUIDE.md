# Oasis Smart City - دليل العمل المشترك والتطوير الجماعي
# Team Collaboration & Extension Guide

هذا الدليل مخصص لأعضاء فريق العمل لشرح كيفية تشغيل المشروع على أجهزتهم، وفهم هيكل الملفات، وإضافة مساهماتهم وتطويراتهم الجديدة (بيانات، نماذج، شاشات) دون حدوث تضارب أو أخطاء.

---

## 1. التشغيل السريع على جهازك (Quick Start)

### الخيار أ: تشغيل لوحة التحكم مباشرة (بدون بايثون نهائياً)
* انقر مرتين على الملف: `open_dashboard_direct.bat`
* أو افتح الملف مباشرة في متصفحك: `Output/dash_1.html`
* **النتيجة:** ستفتح لوحة التحكم التنفيذية الشاملة بكامل تحليلات القطاعات الثمانية، ومنظومة الإنذار المبكر، وتوقعات الشكاوى للـ 15 يوماً القادمة، مع جميع الرسوم البيانية التفاعلية وفلاتر الوقت بنسبة 100%.

### الخيار ب: تشغيل المنصة الكاملة مع بوابة المواطنين التفاعلية (مع بايثون)
* **على نظام Windows:** انقر مرتين على `run_oasis.bat`
* **على نظام macOS أو Linux:** افتح الطرفية ونفذ:
  ```bash
  bash run_oasis.sh
  ```
* **النتيجة:**
  - يتم فتح لوحة التحكم في المتصفح تلقائياً.
  - يبدأ خادم البوابة على المنفذ `5000`:
    - بوابة المواطنين: `http://127.0.0.1:5000/portal`
    - صفحة رفع وتصنيف الدفعات: `http://127.0.0.1:5000/batch`
    - تحليلات النموذج: `http://127.0.0.1:5000/model-analytics`
    - واجهة التنبؤ البرمجية: `http://127.0.0.1:5000/forecast`

## 3. كيفية إضافة ميزاتك الجديدة إلى المشروع (How to Extend)

### أولاً: إضافة بيانات جديدة (New Datasets)
* أنشئ مجلداً فرعياً باسم فريقك أو تخصصك داخل `Datasets/`:
  `Datasets/your_module_data/`
* ضع ملفات الـ CSV أو JSON داخله.
* **قاعدة المسارات الذهبية:** لا تستخدم مسارات مطلقة مثل `C:\Users\...`. استخدم دائماً المسار النسبي المعتمد في المشروع:
  ```python
  import os
  BASE_DIR = os.path.dirname(os.path.abspath(__file__))
  MY_DATA_PATH = os.path.join(BASE_DIR, "Datasets", "your_module_data", "my_data.csv")
  ```

### ثانياً: إضافة نموذج ذكاء اصطناعي جديد (New AI Model)
* ضع كود ونموذج التجربة داخل مجلد منفصل باسمك أو باسم الوحدة:
  `Models/your_model_name/`
* لربط النموذج بالبوابة الموحدة `citizen_app.py`:
  1. استورد كود الاستدلال الخاص بك داخل `citizen_app.py`.
  2. أضف نقطة نهاية (Endpoint) جديدة:
     ```python
     # مثال لإضافة نقطة استدعاء جديدة:
     @app.route("/api/your-feature", methods=["POST", "GET"])
     def handle_your_feature():
         # معالجة الطلب وإرجاع النتيجة بتنسيق JSON
         return jsonify({"status": "success", "result": data})
     ```
  *(ملاحظة: يدعم التطبيق تلقائياً نمطي Flask و http.server القياسي)*.

### ثالثاً: إضافة شاشة أو تبويب جديد في لوحة التحكم (`dash_1.html`)
لوحة التحكم مصممة بنظام التبويبات المعيارية (`data-tab`):
1. **أضف زر التبويب في الشريط العلوي والقائمة الجانبية:**
   ```html
   <button class="tab-btn" data-tab="my_feature">الميزة الجديدة (My Feature)</button>
   ```
2. **أضف حاوية العرض داخل عنصر المحتوى الرئيسي:**
   ```html
   <div id="viewMyFeature" class="tab-view" style="display:none;">
     <!-- ضع بطاقاتك ورسوماتك هنا -->
   </div>
   ```
3. **اربط دالة إظهار التبويب داخل دالة `showTab(tab)`:**
   ```javascript
   var vMy = document.getElementById('viewMyFeature');
   if (vMy) vMy.style.display = (tab === 'my_feature') ? '' : 'none';
   ```

## 4. نصائح هامة للمشاركة وتجنب التعارض (Best Practices)

1. **قبل إعادة ضغط المشروع ومشاركته:**
   * شغل دائماً ملف `clean_before_zip.bat`.
   * يقوم هذا السكربت بمسح ملفات `__pycache__` والملفات المؤقتة لتصغير حجم الملف ومنع تضارب إصدارات بايثون بين الأجهزة.
2. **عند فك الضغط (Windows MAX_PATH):**
   * انصح زملائك بفك الضغط في مسار بسيط (مثل `C:\Oasis` أو على سطح المكتب مباشرة) لتجنب أخطاء ويندوز عند التعامل مع مسارات المجلدات الطويلة.
3. **تجنب مسح عمل الآخرين:**
   * اجعل إضافاتك في ملفات ومجلدات مستقلة قدر الإمكان.
   * عند تعديل `citizen_app.py` أو `dash_1.html`، ضع تعليقاً واضحاً باسمك والميزة المضافة.
